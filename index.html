01 — Scoring framework

Response scoring rubric

A generic template illustrating the rubric-based evaluation approach used in AI/LLM annotation work — every response is scored 0–3 across four dimensions. Hover a score to see it lift.

Dimension 0 · Poor 1 · Weak 2 · Good 3 · Excellent
Relevance ignores request partial match minor gaps fully precise

Coherence disorganized unclear parts minor awkwardness clear order

03 — Annotation guideline

Query intent classification

An example framework for classifying user query intent, the kind used in search / RAG evaluation work.

Informational

User wants to learn or understand something.

"how does photosynthesis work"

Navigational

User wants to reach a specific site or page.

"facebook login"

Transactional

User wants to complete an action.

"buy iphone 15 case"
