03 — Case studies

The work, at concept level

Each card is a kind of task, not a client write-up. Names of projects, private guidelines, and real task data stay off this page.

Mercor · Oct 2026 – Present

AI image evaluation

I compare two AI-generated images made for the same prompt, pick the stronger one, and write a justification from what is actually in the image. The checks are prompt adherence, visual defects such as broken shapes or damaged detail, aspect ratio, and text rendered in the image, including text in more than one language.

Mercor · Data engineering contract · Oct 2026

Agent benchmark, dataset pipeline, and automated scoring

One contract to build an exam-style task for an AI agent, from the design through a score that does not need a person in the loop.

  1. Task design The agent has to choose training data for fine-tuning a language model. Constraints are explicit, and the score is something you can measure.
  2. Dataset pipeline A large multilingual instruction set from public sources, then personal-data filtering, duplicate removal, and a length limit.
  3. LoRA fine-tuning and scoring A GPU service in Python, PyTorch, LoRA, and Docker trains a model and scores it on a held-out question set I wrote.
  4. Calibration I measured a baseline, reference-run scores, and score noise, then revised the task from CI checks and reviewer feedback.

Appen (CrowdGen)

RAG and SFT evaluation

I judge whether an answer from retrieval-augmented generation, or a candidate for supervised fine-tuning, actually meets the request. Sources are reviewed for authenticity, timeliness, and authority. Cases are discarded when the source is weak, the content is invented, or the media does not match. Complex requests — including ones that need video or earlier turns in a chat — are split into subqueries, and each part is checked against the results. I also mark whether a request is really about a current news topic, using the meaning of the query, how fast engagement is moving, and whether the topic is active in more than one place.

Appen (CrowdGen) · Jun 2026 – Present

Rubric scoring

Model answers are scored 0–3. On this work the dimensions include relevance, objectivity, and persona consistency, for informational, navigational, and transactional queries. The scoring load is about 20–22 responses in a 6-hour day, at a 95%+ accuracy standard. I also rewrite answers so the logic, citations, and media fit, and I review golden responses to remove critical errors before delivery. Intent and the reason for a chat turn are logged as structured fields. The 0–3 template in this repository is a public illustration. It is not that project’s rubric.

Appen (CrowdGen) · Oct 2025 – May 2026

Search relevance

I rate how well search results match a query, against quality guidelines, in support of ranking. The same period included image, video, and document classification, sentiment analysis, and light product testing on a high-volume task flow.

OneForma (Centific) · Jul 2026 – Present

Indonesian verbatim audio

Long-form Indonesian podcasts, often half an hour and sometimes past an hour, are transcribed as spoken. Informal words, fillers, stutters, and repetitions are not edited into formal sentences. Speakers are labeled and each turn is timed to the millisecond, within about ±500 ms. Tags cover laughter, fragments, truncated speech, and speech that is hard to hear, and secondary speakers are segmented too. Accent, noise, and mixed language are noted when they matter for speech-model data.

Remotasks (Scale AI) · Jan 2025 – Sep 2025

Robotics video annotation

Demonstration video is labeled for scene attributes, events, and sub-actions such as pick up, hand off, assemble, insert, approach, and align. I judge how well the robot carried out the task and flag a failed grasp or a mistimed clip, across more than one camera, before the clip is submitted.

Vision-language-action data

Hand-action video captioning

Separate from the robot-video labeling, I caption training video of human hands at work — for example welding, or fastening and unfastening bolts. The clip is split into time segments. Each segment gets a simple, natural English description of the action, in ordinary wording rather than a stiff generated style.

Welocalize · Jul 2026 – Aug 2026

Public rubric, illustrated

Original template for this portfolio. Not an employer rubric. Real projects change the dimensions. The scoring work described above used relevance, objectivity, and persona consistency. Those private level definitions are not copied here.

Relevance

  1. 0 Ignores the request
  2. 1 Partial match
  3. 2 Minor gaps
  4. 3 Fully precise

Factual accuracy

  1. 0 Clear errors
  2. 1 One notable error
  3. 2 Minor imprecision
  4. 3 Verifiable claims

Coherence

  1. 0 Disorganized
  2. 1 Unclear in places
  3. 2 Minor awkwardness
  4. 3 Clear order

Tone and persona

  1. 0 Inappropriate
  2. 1 Occasional slips
  3. 2 Minor lapses
  4. 3 Consistent

Worked example — invented

Prompt: “What’s the best way to store leftover rice safely?” Full score table and rationale: example-response-scoring.md.

A · tie 12/12

Rice should be cooled within 1 hour and refrigerated in a sealed container for up to 3–4 days.

B 5/12

Just leave it on the counter, rice doesn’t really go bad.

C 5/12

Store it. Cold place. Container. Good.

D · tie 12/12

Refrigerate promptly in an airtight container; consume within a few days to avoid bacterial growth.

A and D both score 12. The golden response is written from both: A’s storage window, and D’s reason (bacterial growth). B is down-scored for a food-safety error. C is down-scored because it reads as fragments, not an answer.

Query intent — the categories

A generic framework for the kind of intent labeling used in search and RAG evaluation. The guideline, including ambiguous cases, is in the full note.

Informational

The user wants to learn or understand something.

how does photosynthesis work

Navigational

The user wants a specific site, page, or product.

facebook login

Transactional

The user wants to complete an action.

buy iphone 15 case

Toy data-cleaning step

The script samples/pii_filter_dedup.py redacts an obvious email and a fictional phone number, drops an over-long row, and collapses whitespace duplicates. Ordinary numbers such as “3 to 4” are left alone. Run it with python3 samples/pii_filter_dedup.py.
